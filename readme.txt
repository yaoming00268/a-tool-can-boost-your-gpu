Nanako App Manager（NVIDIA 显卡高频锁频工具 / GPUBooster）v1.1.0
=============================================================

一款面向 Windows 的 GPU 频率管理与软件调度中心：
- 按前台/运行进程自动锁定或限制 NVIDIA 显卡核心频率（定频/频段模式）
- 平滑调频缓冲，硬件极限自动探测与超限截断保护
- 微星小飞机 (MSI Afterburner) 配置方案联动与 V-F 曲线编辑器唤起
- 软件库管理：分类分组、排队/焦点双调度、使用统计、电源计划自动切换
- 毛玻璃拟态 WebView2 界面，支持自定义壁纸/主题色/透明度/模糊
- 插件体系：plugins 目录内 .py 文件自动发现加载（可自行扩展）

使用须知
--------
1. 锁频功能必须以【管理员身份】运行（程序会自动弹出 UAC 提权）。
2. 仅支持 NVIDIA 显卡（驱动需支持 nvidia-smi），A 卡暂无适配。
3. 超频/锁频有风险：内置硬件极限截断保护，但仍可能导致系统不稳定
   或蓝屏，请在小幅频率下验证稳定性后逐步调整，后果自负。
4. 默认全局热键 F12：一键开启/停止监控。
